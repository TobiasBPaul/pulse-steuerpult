# Pulse Steuerpult

Eine Webseite, die ein Soundbrenner-Pulse-Metronom per Bluetooth steuert: Start/Stopp, Tempo, Taktart, Akzentfarben, Vibrationsmuster, Akkustand.

Öffnen in Chrome auf Android (Web Bluetooth). Die Soundbrenner-App vorher schließen.

Inoffiziell, nicht von Soundbrenner. Am echten Gerät noch nicht getestet.
